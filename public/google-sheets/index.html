Google 雲端存檔設定

已綁定 Howard 提供的試算表。適用少於 10 位同時遊玩的朋友；每個角色使用獨立恢復碼，每 60 秒同步。

1. 複製程式

下載 Code.gs

2. 貼上並初始化

  1. 開啟指定試算表。
  2. 選擇「擴充功能 → Apps Script」。若已有其他程式，新增一個腳本檔，保留原程式；若已有 doGet 或 doPost，請先告知，避免衝突。
  3. 在空白專案的 Code.gs 貼上完整程式，儲存。
  4. 上方函式選擇 setup，按「執行」，由你本人完成 Google 授權。

程式只新增 TitanEcho_Saves_v1 分頁。重複執行不會清除存檔，也不修改其他分頁。

3. 部署

  1. 右上角「部署 → 新增部署作業」。
  2. 類型選「網頁應用程式」。
  3. 「執行身分」選「我」。
  4. 「誰可以存取」選「所有人」，讓遊戲可以從 GitHub Pages 連線。試算表本身保持私人。
  5. 按「部署」，將結尾為 /exec 的網頁應用程式網址貼回對話。

如果公司帳號沒有「所有人」選項，請告知實際選項；不要把試算表改成公開。

4. 完成連線後遊玩

取得部署網址後，我會啟用遊戲設定。玩家從「設定 → Google 雲端存檔」建立角色並下載恢復碼。換裝置時輸入相同恢復碼，預覽後確認載入。

先在舊裝置「立即同步雲端」，再切換裝置。同一角色請一次使用一台裝置，雲端版本衝突時會暫停上傳。

這是朋友間的雲端存檔，不是防作弊競技伺服器；排行榜仍為本機紀錄。Google Apps Script 的實際連線與跨來源回應需於部署後驗證。
