存檔修正

舊神器 ID 不會直接被改名成另一件神器。首次載入時，全額返還可追蹤的舊神器投入，舊等級與投入另存；關卡、金幣、最高紀錄與舊收藏保留。主動技能重置為未購買，避免把前版等級套到不同規則。這是相容性遷移，不是原版遊戲機制。

GitHub Pages 會在 IndexedDB 保存一份修正前完整備份 before-tt2-migration，可從遊戲設定匯出。Google Sheet 的外層儲存格式維持不變，二代資料位於獨立欄位，既有 Apps Script 不需重新部署。
